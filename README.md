# Personal web presentation - Milos Adzic

Homework 1 of the course *Developing Software Solutions* (professor Aleksandar Kartelj):
a small site about myself, made with HTML, CSS and Bootstrap 4.5.2, published with GitHub Pages.

The site: https://adzicmilos-star.github.io/personal-site/

## The files

| File | What it is |
|---|---|
| `index.html` | the home page: photo, a few words about me, cards that lead to the other pages |
| `career.html` | a table of jobs, cards of skills with badges, an ordered list |
| `interests.html` | the course (two columns, an alert, a list group), nested lists, cards |
| `contact.html` | a form with validation; it opens `thanks.html` |
| `thanks.html` | the page shown after the form is sent |
| `css/site.css` | our own style rules, linked after Bootstrap, with one media query |
| `images/photo.svg` | the photo on the home page |

## How to look at it on your own computer

Double click `index.html`. The browser needs an internet connection, because Bootstrap comes from a CDN.
