Developing Software Solutions

The course of professor Aleksandar Kartelj shows how web applications work and how to build one: from a single HTML page to a complete system with a web application, a RESTful service and a database.

Everything about it is public: the web site of the course.

This site is Homework 1 of the course.
  • Homework 1: a personal site 15
  • Homework 2: a web application 15
  • Project: a complete system 30
  • Final exam 40

What I learned for this site

  • HTML - the content of a page
    • headings, paragraphs and lists
    • images, links and tables
    • forms
  • CSS - the look of a page
  • Bootstrap - pages that adapt to every screen
